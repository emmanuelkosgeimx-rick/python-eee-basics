1. Simple Inventory System
   This is a beginner-level Python project that uses a dictionary to manage electronic components and their quantities.
   It demonstrates how to add, remove, search for, and update items in an inventory.
   
How It Works:
The program starts with three components: 5 resistors, 2 capacitors, and 1 diode.
Adding a component: Adds 11 transistors to the inventory.
Removing a component: Deletes the diode from the inventory.
Searching: Searches for a transformer. Since it isn't in the inventory, the program prints Not found!.
Updating quantities: Changes the resistor quantity from 5 to 20 and the transistor quantity from 11 to 8.
Displaying inventory: Prints the final inventory with the updated quantities.

Example Output:
Not found!
{'resistor': 20, 'capacitor': 2, 'transistor': 8}

How to Run:
Make sure Python 3 is installed, then open a terminal in the project folder and run:
python simple_inventory_system.py
